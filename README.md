# 海外AIサービス調査 → 次期商材MVP開発プロジェクト

## プロジェクト概要

| 項目 | 内容 |
|---|---|
| 目的 | 海外で展開済み・日本未展開のAIサービスを調査し、次期商材のMVP要件定義〜開発〜プレゼン〜稟議〜本開発へ進める |
| ターゲット | 美容室・飲食店・工務店などの中小企業（SMB） |
| 価格帯 | 月額 ¥5,000〜50,000 のサブスクリプション |
| 重要要件 | 解約されにくいこと。**クライアントが儲かる構造**（収益貢献が円建てで見える）をつくることで、当社への支払い原資を生む |

## 背景

当社はWEB制作会社。WEBサービスのコモディティ化により制作費用が下落し、割賦販売から月額サービスへ移行済み。収益性悪化への対応としてMEO・SNSサービスをこの10年展開してきたが、AIサービスの台頭を受け次の商品開発の機会を探っている。

### 既存AI商材

| 商材 | 内容 |
|---|---|
| MEOエージェント | MEOツールのAIエージェント化 |
| 建築リフォームエージェント | 現況画像+希望 → リフォーム後画像をAI生成（工務店向け） |
| サイトマイスター | クライアント情報 → AIがWEBサイト3パターン生成。動画・画像もAIが用意、多言語対応 |

## 現時点の結論（2026-07-14 更新）

売るのはAIではなく「毎月の儲けの証拠」。全商材を共通の**円建て成果ダッシュボード**に載せる。

MVPは**直販オンライン注文システム**（Uber Eats/出前館の手数料35〜40%を回避し、テイクアウト・自店配達の直接注文を増やす。Owner.com型）。WEB制作・MEO・サイトマイスターとの相性が最も良く、既存飲食クライアントへ即アップセルできるため、調査時のPhase 3から前倒しで採用。

- **Phase 1（MVP）**: 直販オンライン注文システム（→ [要件定義書](docs/03_要件定義_直販オンライン注文システムMVP.md)）
- **Phase 1 並行**: D. AI検索対策（LLMO）アドオン（MEO既存顧客へ即販売、開発ほぼ不要）
- **Phase 2**: B. AI掘り起こしエンジン（注文システムが蓄積する顧客リスト上のリピート促進モジュールとして統合）+ Uber Direct連携
- **Phase 3**: 統合フラッグシップ（日本版Owner.com：サイト+MEO+注文+リピートAI+成果ダッシュボード）
