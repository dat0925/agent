# 第2弾調査：WEBマーケティング軸・収益直結型AI商材（現行の推奨方針）

- 調査日: 2026-07-14
- 思想の転換: 「機能ロックインで解約させない」→「**クライアントが儲かるから解約されない**」
  - クライアントが収益を得る（儲かる）構造をつくらないと、当社に支払う原資がない、という依頼元の思想に基づく
- 設計原則: **「AIツール」を売らない。「今月このサービスがあなたの店に¥Xの売上をつくった」と円建てで見えるレポートごと売る**

## 調査で最も明確だった教訓

- AI広告クリエイティブ・AI分析ツールなど「成果が円で見えない」商材はSMBでは解約率が高い
- 予約・注文・売上そのものを取り込み「円建てダッシュボード」で成果を見せる商材が急成長している

## 1. 思想を体現する海外の成功例

### 1-1. Owner.com（飲食店・米国）— 直販売上エンジン ★最重要ベンチマーク
- 内容: 月額$499フラットで、Google最適化サイト+SEO+手数料ゼロのオンライン注文（配達はDoorDashドライバー網）+メール/SMS自動マーケ+ロイヤルティ+ブランドアプリを一括提供
- 成果指標: ARR $34M→**$80.5M（前年比+137%）**、評価額**$1B**、累計調達$189M（2025年5月 Series C）
- 儲かる構造: DoorDash等の20〜30%手数料を回避した金額と直販売上をダッシュボードに毎月表示 → 「サブスク費が毎月自動的にペイする」
- 日本での示唆: 食べログ・ホットペッパー・出前館/UberEatsの掲載料/手数料の痛みは米国と相似。**日本版は不在**
- 出典: [Sacra: Owner](https://sacra.com/c/owner/) / [Owner.com pricing](https://www.owner.com/pricing)

### 1-2. Hatch（工務店・ホームサービス・米国）— スピード・トゥ・リード + Rehash
- 内容: 問い合わせに数秒でAIが音声/SMS/メール応答（speed-to-lead）。失注見積もりへのAI再アプローチ「Rehash」
- 成果事例: Rehashで$7Mの追加受注、時間外の商談化3倍
- 儲かる構造: 受注単価が大きい業種ほど「1リード救出=年間費用回収」の算数が成立
- 出典: [Hatch](https://www.usehatchapp.com/) / [Hatch pricing analysis](https://serviceagent.ai/blogs/hatch-pricing/)

### 1-3. データベース・リアクティベーション（美容室・ローカルSMB・米国）
- 内容: 店の既存顧客リスト（休眠客）にAIがSMS/メールで会話し、返信対応から予約まで自動化
- 販売形態: GoHighLevel系エージェンシーが成果報酬（予約1件あたり課金）または$500〜2,000/月で販売。返信率2〜20%、事例で休眠客の最大40%再活性
- 儲かる構造: **キャンペーンそのものが帰属計算**（X通送信→Y返信→Z予約×客単価=¥）。広告費ゼロ、30日以内に成果が見える
- 関連: GlossGenius（美容室SaaS $24/$48/$148月）は「初年度売上+26%」を訴求
- 出典: [Cometly: Database Reactivation](https://www.cometly.com/post/database-reactivation) / [ROI guide](https://octavius.ai/database-reactivation-roi/) / [GlossGenius pricing](https://glossgenius.com/pricing)

### 1-4. GoHighLevel — 代理店向けホワイトレーベル「ローカル収益エンジン」
- 内容: CRM+ファネル+SMS/メール自動化+予約+口コミ管理+パイプライン/帰属分析のオールインワン。代理店が$97〜497/月で契約し、地域ビジネスに$97〜997/月で再販
- 経済性: $497プランで10クライアント×$297再販 ≈ 粗利$2,473/月
- 日本の状況: 真の同等品なし。GHL自体は日本語/LINE対応が弱い。L-Step（LINE）やUTAGE（ファネル）が断片的に存在するのみ。**代理店再販型の統合基盤は空白**
- 出典: [GHL pricing](https://www.gohighlevel.com/pricing) / [agency economics](https://netpartners.marketing/gohighlevel-agency-pricing-guide/)

### 1-5. 帰属分析・コールトラッキング（レポーティングの背骨）
- 海外: CallRail（$55〜215/月、広告/キーワード単位のコール帰属+AI文字起こし・リードスコア）、WhatConverts（$30〜159/月）
- 儲かる構造: 「Googleマップ経由で34コール→12予約→¥310,000」という報告が可能に。MEOレポートと直結
- 日本の状況: CallTracker（¥15,000/月〜）、Delacon（¥32,500/月〜）と高価格・企業向け。**SMB向け低価格帯+AI会話分析は空白**
- 出典: [CallRail](https://www.callrail.com/conversational-ai-platform) / [CallTracker](https://www.calltracker.jp/price/)

### 1-6. その他の調査結果（見送り判断の根拠）
- **AI広告運用（SMB向け）**: Bïrch($49〜99/月)はEC/代理店向け。Kliken($75/月〜広告費込み)はサイトビルダー同梱型。月広告費$1,000未満の純粋なAI広告ツールは成立しにくい → 単体では見送り
- **AI広告クリエイティブ生成**: AdCreative.ai($39〜139/月), Pencil($14〜/月)。利用者はECと代理店中心。**収益帰属ストーリーがなく解約リスク大** → 見送り
- **AI LP/CVR最適化**: Unbounce Smart Traffic（平均+30%のCVR改善だが$249/月のマーケター向け）→ ローカルSMB向けの証拠薄い → 見送り
- 出典: [Kliken](https://www.kliken.com/pricing.html) / [Unbounce review](https://hackceleration.com/unbounce-review/)

## 2. AI検索対策（LLMO/AEO/GEO）— MEOの正統進化

### 市場の変化（データ）
- 消費者のAIによる地域ビジネス探し: 米国で6%（2025）→ **約45%（2026）**。Googleとの併用でAIは第3の発見チャネルに（BrightLocal LCRS）
- AI Overviews は米Google検索の約60%に表示（2026年4月）、ローカルクエリの約40%。引用されたブランドはクリック+35%
- AI経由の参照流入はまだ全体の約1%だが**前年比+527%**で成長、CVRは通常検索の**4.4〜23倍**
- 日本: 生成AI利用率はネットユーザーの50%超（ドコモ/ICT総研 2026）。**AI検索利用率は約37%（2026年2月、11ヶ月で3.5倍）**
- 現在AIに推薦されるローカルビジネスは約1.2%のみ → 先行者利益が実在
- 出典: [BrightLocal LCRS](https://www.brightlocal.com/research/lcrs-ai-trust/) / [AI search stats](https://serps.io/blog/ai-search-statistics-2026) / [AI referral traffic](https://thestacc.com/blog/ai-search-referral-traffic-stats/) / [ledge.ai ドコモ調査](https://ledge.ai/articles/genai_usage_japan_docomo_survey_2026)

### 施策として効くもの（優先順）
1. **Bing Places** — ChatGPTのローカルデータはBing経由。最も見落とされているレバー
2. **第三者サイトでの言及・引用**（口コミポータル、リスト記事、地域メディア）— 最大の重み(約12%)。NAP不整合はランキング約41%低下
3. **口コミの量と鮮度**（Google/Bing/食べログ/ホットペッパービューティー等をAIが相互照合）
4. **GBP最適化**（Gemini/AI Overviewsに直結。既存MEO業務がそのまま活きる）
5. **構造化データ（LocalBusiness schema）、FAQ形式ページ、クロール可能なHTML**
6. **llms.txtは効果なし**（Ahrefs: 97%が一度も取得されず。主要AIベンダー非対応）→ 売り物にしない

### 日本の競合状況
- LLMO/AIO/GEOコンサルは多数出現（S&Eパートナーズ、エイチリンク等）だが**¥150,000〜800,000/月の企業向け**
- 低価格帯: MEO4980（MEO+LLMO ¥4,980/月）、商売繁盛AI（¥49,800/月〜）
- **¥10,000〜30,000のプロダクト化された中間帯が空白**
- 「LLMO対策は情弱ビジネス」という批判言説も既に存在 → 計測可能性・誠実さが信用の鍵

### ROIの見せ方
- GA4カスタムチャネルグループで chatgpt.com / perplexity.ai / gemini 参照元をタグ付け →「今月AI経由でX人来訪」
- **プロンプト・シェア・オブ・ボイス レポート**: 「○○市 おすすめ 美容室」等の定点プロンプト20〜30本を毎月ChatGPT/Gemini/Perplexity/AI Overviewsで実行し、言及率・順位・競合比較を報告（MEOの順位グリッドレポートと同じ見せ方）
- 予約フォームに「AIで見た」チェックボックス

### 月次成果物（¥15,000〜30,000プラン想定）
1. AI推薦シェアレポート（定点プロンプト・競合比較・スクリーンショット）
2. Bing Places + GBP + ディレクトリ/NAP整備
3. 口コミ生成・返信運用
4. AIに引用されるコンテンツ月1本（FAQ/schema対応ページ、リスト記事掲載交渉）
5. GA4 AI流入ダッシュボード
6. 四半期「AIに聞いてみた」ビフォーアフターデモ（営業的クロージャー）

### B. AI掘り起こしエンジン（総合4.5 — MVP本命）
- 内容: 美容室・飲食店の休眠顧客リストにAIがLINEで会話し予約まで自動化。成果を円建てレポートで毎月提示
- 想定価格: ¥19,800〜49,800/月、または予約1件あたり成果報酬のハイブリッド
- 広告費: ゼロ（店の既存顧客リストが原資）。ホットペッパー掲載料高騰へのカウンター提案
- 国内空白: LINE配信ツールはルールベース止まり。AI会話×予約完結×円建て成果報告は未確立
- **儲かる構造の例**: 送信500通 → 返信40件 → 再来店14件 × 客単価¥7,000 = **¥98,000/月の売上創出**。月額¥29,800ならROI 3.3倍が毎月見える

### D. AI検索対策(LLMO)アドオン（総合4.2 — 即併売できる第2の矢）
- 内容: ChatGPT・Gemini・AI Overviewsに推薦される状態をつくる。MEOの正統進化
- 想定価格: MEO契約への+¥10,000〜15,000アドオン（単独¥15,000〜30,000）
- 原価: Local Falcon/Otterly等 $25〜30/月/店舗と低い
- 注意: 単独では店舗あたりAI流入がまだ小さい → **MEOとのセット販売**が現実的

### A. 直販売上エンジン（総合3.8 — 中期フラッグシップ）
- 内容: サイト+MEO+手数料ゼロの直販予約/注文+LINEマーケ一括。「直販売上¥X/ポータル手数料¥Y削減」を毎月表示
- 想定価格: ¥30,000〜50,000/月
- 課題: 予約/注文/決済まで含み開発規模最大。Phase1の収益とデータを土台に段階投資
- **儲かる構造の例**: ポータル経由売上¥100万/月の店なら手数料10〜30%=¥10〜30万。一部を直販に移すだけで月額費を大きく上回る削減額が見える

### C. 高速リード対応AI（総合3.7 — Bのエンジン転用で展開）
- 内容: 問い合わせ即時AI応答+失注見積もりのAI再アプローチ（Rehash）
- 想定価格: ¥50,000/月（リフォーム単価¥50万〜300万なので月1件のリード救出で正当化）
- 留意: 商談サイクルが長く成果可視化に90日〜。B完成後の横展開が効率的
- **儲かる構造の例**: 失注見積もり20件にAI再アプローチ → 商談2件 → 受注1件¥120万。1件で年間費用の2倍を回収

## 4. 推奨ロードマップ（現行方針）

共通基盤 = **円建て成果ダッシュボード**。全商材が同じレポート様式で成果を語る。

| Phase | 商材 | 理由 |
|---|---|---|
| Phase 1（MVP） | B. AI掘り起こしエンジン（美容室から） | 広告費ゼロ・30日以内に円建て成果。LINE連携+AI会話+予約導線+成果レポートの4点に絞れば開発規模最小級。稟議も「初月から成果数値が出る」ため通しやすい |
| Phase 1 並行 | D. AI検索対策(LLMO)アドオン | 開発はレポート自動生成中心で軽い。MEO既存顧客に即販売でき、Bの開発期間中のキャッシュ確保と市場先行の両取り |
| Phase 2 | C. 高速リード対応AI（工務店） | Bの会話AI・追客エンジン・成果レポート基盤を再パッケージ。高単価業種で価格上限¥50,000を狙う |
| Phase 3 | A. 直販売上エンジン（飲食店版Owner.com） | サイトマイスター+MEO+B/D基盤を統合した旗艦商品。「ポータル依存から直販へ」。単品売りから「売上をつくる月額パートナー」への業態転換が完成 |

## 結論

**売るのはAIではなく「毎月の儲けの証拠」。** Phase 1のBとDから着手し、すべての商材を同じ円建て成果ダッシュボードの上に載せることで、商材が増えるほど解約理由が消えていく構造をつくる。
