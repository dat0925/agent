01｜エグゼクティブサマリー

何を・なぜ・いくらで・いつまでに

商品飲食店の自社サイトに手数料ゼロのオンライン注文（テイクアウト・自店配達）を組み込み、「直販売上¥X／節約した手数料¥Y」を毎月見せる月額サービス（¥29,800/月）
なぜ今かUber Eats手数料35%・出前館最大40%への店舗の不満が顕在化。米国では同モデルのOwner.comがARR $80.5M（前年比+137%）と急成長。国内に「集客と成果表示まで一体」の競合は不在
なぜ当社か注文の入口は店のWEBサイト。サイト制作+MEO+SNSを握る当社は「注文が入る状態」まで一気通貫で作れる唯一のポジション。既存飲食クライアントへのアップセルで営業コストほぼゼロ
投資MVP開発 8週間・約3人月 ＋ 外部サービス実費（Stripe/Supabase/LINE/Claude API 月数万円）
検証既存飲食クライアント3〜5店舗で90日パイロット。「節約額＞月額費」達成店舗率80%以上等のKPIで本開発をGO/NO-GO判断
依頼事項MVP開発着手・パイロット提供枠（無償〜半額）・外部サービス利用の承認

06｜MVPスコープ

「注文が流れ、節約額が見える」ことの検証に徹する

顧客側（店のお客様）

・スマホ注文ページ（サイトから遷移/埋め込み）
・メニュー閲覧・オプション選択
・テイクアウト（日時指定）／自店配達（エリア・最低注文額・配達料）
・Stripeクレジット決済＋店頭払い
・ゲスト注文（会員登録不要）・注文確認通知

店舗側

・メニュー管理＋AIメニュー作成支援
・注文受信（管理画面＋LINE通知）・ステータス管理
・営業時間・時間枠・注文停止スイッチ
・円建て成果ダッシュボード＋月次レポート自動生成
・顧客リスト蓄積

MVPでやらないこと（Phase 2以降）

・PayPay決済・LINEログイン/再注文
・Uber Direct連携（配達外注）
・AIリピート促進（休眠客掘り起こし）
・POS/レジ連携・独自アプリ・複数店舗管理・多言語

システム構成

・Next.js（Vercel）＋ Supabase（リアルタイム通知・テナント分離）
・Stripe Connect：売上は店舗口座に直接入金（当社は資金を預からない＝資金決済法リスク回避）
・LINE Messaging API（店舗通知）・Claude API（AI機能）
・マルチテナント設計で店舗追加の限界費用ほぼゼロ

09｜リスクと承認依頼事項

リスクは限定済み。MVP開発着手の承認を依頼します

リスク対応
無料競合とのコモディティ化集客+成果証明+AIの統合で土俵を変える
注文が入らない店の即解約導入条件設定・MEO/SNSセット販売・利用低下検知でCS介入

① MVP開発着手（8週間・約3人月）
